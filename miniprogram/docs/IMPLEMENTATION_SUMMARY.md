## 使用指南

### 普通鉴定员

**可以做什么：**
1. 查看团队信息（设置 → 团队 → 团队信息）
   - 查看所有鉴定员的认证状态
   - 查看所有鉴定员的牧场匹配情况

2. 设置DHI编号（选择牧场时）
   - 为缺少DHI编号的牧场补充DHI

3. 导出当前牧场所有记录（评分记录 → 批量导出）
   - 切换到"全部"筛选
   - 点击"批量导出"

4. 只能编辑/删除自己的记录

**不能做什么：**
- 创建牧场
- 关联鉴定员到牧场
- 删除牧场
- 设置其他人的角色
- 编辑/删除他人的记录

---

### 管理员

**除了普通鉴定员的所有权限外，还可以：**
1. 访问管理后台（设置 → 管理功能 → 管理后台）

2. 关联鉴定员到牧场（管理后台 → 牧场匹配）
   - 选择鉴定员
   - 开启/关闭牧场访问权限

3. 创建牧场（选择牧场 → + 新建牧场）

4. 查看牧场管理（管理后台 → 牧场管理）
   - 查看所有牧场
   - 但只能看到"仅超级管理员可删除"提示

5. 编辑/删除所有人的记录（用于纠错）

**不能做什么：**
- 删除牧场
- 设置其他人的角色

---

### 超级管理员

**除了管理员的所有权限外，还可以：**
1. 设置鉴定员角色（管理后台 → 鉴定员管理）
   - 将普通鉴定员提升为管理员
   - 将管理员降级为普通鉴定员
   - 不能修改其他超级管理员

2. 删除牧场（管理后台 → 牧场管理）
   - 删除牧场
   - 自动清理所有关联关系

3. 查看操作日志（未来功能）

**不能做什么：**
- 修改其他超级管理员的权限
- 将用户直接设为超级管理员

---

## 注意事项

1. **删除牧场是危险操作**
   - 只有超级管理员可以删除
   - 删除前会有二次确认
   - 删除会清理所有关联关系
   - 无法恢复

2. **权限边界**
   - 管理员不能设置角色
   - 超级管理员不能修改其他超级管理员
   - 普通鉴定员不能修改他人记录

3. **数据安全**
   - 所有操作都有权限检查
   - 前端和后端（未来）都需要验证
   - 建议添加操作日志功能

4. **性能考虑**
   - 团队信息页面加载所有数据
   - 如果鉴定员/牧场数量很大，考虑分页
   - 导出功能可能需要限制导出数量
