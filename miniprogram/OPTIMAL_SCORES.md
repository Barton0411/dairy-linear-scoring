# 评分界面最优值标记功能说明

## 功能概述

在评分界面中，各性状的最优值会以特殊方式标记，帮助鉴定员快速识别理想分数。

## 最优值配置

各性状的最优值已在 `store/index.js` 中定义：

```javascript
const OPTIMAL_SCORES = {
  tg: 8,       // 体高
  xk: 9,       // 胸宽
  ts: 7,       // 体深
  yqd: 9,      // 腰强度
  kjd: 5,      // 尻角度
  kk: 9,       // 尻宽
  tjd: 7,      // 蹄角度
  tgsd: 9,     // 蹄踵深度
  gzd: 9,      // 骨质地
  hzcs: 5,     // 后肢侧视
  hzhs: 9,     // 后肢后视
  rfsd: 5,     // 乳房深度
  zyxrd: 9,    // 中央悬韧带
  qrffz: 9,    // 前乳房附着
  qrtwz: 6,    // 前乳头位置
  qrtcd: 5,    // 前乳头长度
  hrffzgd: 9,  // 后乳房附着高度
  hrffzkd: 9,  // 后乳房附着宽度
  hrtwz: 6,    // 后乳头位置
  ljx: 9       // 棱角性
}
```

## 界面展示特性

### 1. 最优值按钮标记

最优值分数按钮具有以下特殊样式：

- **橙色边框**：2rpx solid #ff9500
- **数字加粗**：font-weight: 700，字号28rpx
- **星标标记**：按钮右上角显示 ⭐ 符号
- **选中状态**：当最优值被选中时，背景变为橙色(#ff9500)

### 2. 分数描述

在分数按钮上方显示性状的两端描述：

- **左侧描述**：对应1分的特征（如"矮小"、"窄"、"浅"等）
- **右侧描述**：对应9分的特征（如"高大"、"宽"、"深"等）
- **样式**：22rpx 灰色字体

**示例**：

```
体高:
矮小                    高大
[1] [2] [3] [4] [5] [6] [7] [8⭐] [9]
```

其中8分按钮会有橙色边框和星标，表示这是体高的最优值。

### 3. 视觉层次

评分按钮有三种状态优先级：

1. **最优值标记**：橙色边框 + 星标
2. **已选中**：蓝色背景（普通分数）或橙色背景（最优值）
3. **默认值**：浅蓝色背景
4. **未使用**：灰色背景

## 技术实现

### 文件修改

1. **store/index.js**
   - 新增 `OPTIMAL_SCORES` 常量
   - 导出 `OPTIMAL_SCORES`

2. **pages/scoring/unified/unified.js**
   - 导入 `OPTIMAL_SCORES`
   - 在 data 中添加 `optimalScores: OPTIMAL_SCORES`

3. **pages/scoring/unified/unified.wxml**
   - 添加分数描述行（显示 low 和 high）
   - 按钮添加 `is-optimal` class
   - 添加星标 `⭐` 显示

4. **pages/scoring/unified/unified.wxss**
   - 添加 `.score-descriptions` 样式
   - 添加 `.score-btn.is-optimal` 样式
   - 添加 `.optimal-mark` 星标样式

## 数据来源

最优值配置基于以下标准：
- GB/T 35568-2017（中国荷斯坦牛体型鉴定分类技术规范）
- T/DACS 002-2021（荷斯坦牛体型鉴定分类操作技术规范）

具体数值参考 `/docs/569e46c1-b527-46aa-8527-112fac00d0a6.pdf` 第19页。

## 使用建议

1. **评分时参考**：最优值不代表所有牛只都应该达到该分数，而是理想状态下的参考值
2. **个体差异**：根据牛只实际情况评分，不必强求所有性状都达到最优值
3. **视觉辅助**：星标和橙色边框帮助快速识别关键分数点，提高评分效率

## 未来扩展

如需修改最优值配置，只需：
1. 编辑 `store/index.js` 中的 `OPTIMAL_SCORES` 对象
2. 修改对应性状的分数值
3. 重新编译小程序

无需修改其他文件，系统会自动应用新的最优值标记。
