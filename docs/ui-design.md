## 主要操作流程

```
┌─────────┐
│  首页   │
└────┬────┘
     │
     ├─── 选择牧场 ───> 牧场选择页
     │
     ├─── 正常模式 ───┐
     │                │
     └─── 缺陷模式 ───┼───> 牛只信息 ──> 评分页 ──> 拍照 ──> 结果
                      │                                      │
                      │                                      │
                      └── 跳过拍照 ──────────────────────────┘
```

## 配色方案

| 元素 | 颜色 | 用途 |
|------|------|------|
| 主色 | #07C160 | 按钮、强调、微信绑定 |
| 辅助色 | #ff9500 | 缺陷模式、警告 |
| 背景 | #f5f5f5 | 页面背景 |
| 卡片 | #ffffff | 内容卡片 |
| 文字主 | #333333 | 标题、重要文字 |
| 文字次 | #999999 | 次要说明 |
